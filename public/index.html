HERDR EXCLUSIVE // 深度视觉定制

外观色板与布局卡片微调

精细定制 Herdr 的侧边栏、底层画布、强调色、分屏卡片圆角/间距/顶栏与极光渐变背景，修改实时在 Herdr 窗口生效。

🎨 Herdr 界面语义色板微调 (Semantic UI Colors)

在当前主题基础上单独微调任意 UI 区域颜色（写入 settings.json -> colors）。点击「清除自定义色彩覆盖」可随时还原为主题原生派生色。

▢ 分屏卡片与边框 (Pane Frames)

控制终端窗格的卡片圆角、间距、单窗格边框与键盘焦点高亮效果。

卡片圆角 (Pane Radius)

每个终端卡片的圆角弧度 (0px 直角 ~ 22px 圆润)

分屏窗格间距 (Pane Gap)

相邻分屏终端之间的留白距离

工作区外边距 (Work Body Padding)

终端区域与窗口四周边缘的呼吸留白

8px
焦点窗格边框颜色 (Focus Border)

当前激活终端窗格的边框颜色策略

焦点边框粗细 (Focus Width)

激活窗格边框线宽 (px)

单窗格也显示卡片框架 (Lone Frame)

未分屏时是否依然保留卡片圆角、边框与顶栏

◫ 顶栏、侧边栏与画布材质

定制窗格顶栏显示模式、侧边栏宽度以及终端内边距与极光渐变画布。

窗格顶栏显示模式 (Pane Header)

窗格顶栏位置与高度

TYPOGRAPHY & ESSENTIALS // 字体与可读性

字体、全局缩放与跨端联动

配置 Herdr 的终端等宽字体、界面 UI 字体、字号、全局缩放倍率与最低对比度保护。

🔤 终端与界面字体 (Fonts)

分别指定终端内代码等宽字体与 Herdr 侧边栏/标签栏 UI 字体。

终端主字体 (Terminal Font)

推荐使用 Maple Mono NF CN（自带中文 2:1 对齐与 Nerd 图标）或 JetBrains Mono

界面 UI 字体 (Interface Font)

侧边栏、标签页、状态栏与弹窗的显示字体

终端基准字号 (Font Size)

Zoom 为 100% 时的基准字号 (实际显示字号 = 基准字号 × Zoom)

编程连字 (Font Ligatures)

启用 !==、=>、-> 等符号连字特性（光标所在处会自动拆开保持清晰）

🔍 缩放、对比度与终端体验

调整全局 DPI 缩放、暗淡文本对比度提亮阈值与键盘交互细节。

全局缩放比例 (Global Zoom)

等比缩放整个 Herdr 窗口的所有终端文字、侧边栏与图标

最低对比度保护 (Minimum Contrast)

自动提亮低于该对比度阈值的暗淡注释文字 (1.0 为关闭，推荐 1.6 ~ 3.0)

macOS Option 键行为 (Option as Alt)

控制 Option 键用于终端 Alt 快捷键还是输入特殊字符

显示终端滚动条 (Pane Scrollbars)

当终端存在历史滚动缓冲区时在右侧边缘显示细滚动条

Agent 状态提示音 (Alert Sounds)

当后台 Agent 完成任务或需要人工确认时播放提示音
